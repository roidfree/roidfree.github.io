The video "React Native Isn't as Popular as You Think" critically examines the actual popularity and usage of React Native in mobile applications, contrasting common perceptions with observed realities. The creator investigates claims about major apps like Walmart and Facebook using React Native and demonstrates how to verify an app's underlying framework by analyzing its compiled files.


Here are the main points:

- **Discrepancies in showcases and articles:** The React Native showcase and various articles often incorrectly claim that major apps use React Native, when in reality, they use native code or different frameworks.
- **Verification methods:** The video explains technical methods for determining an app's framework, such as decompiling iOS IPA files and Android APK files.
- **Corporate interests in marketing frameworks:** The video suggests that consulting companies contribute to marketing that inflates React Native's perceived popularity.
- **Shift towards native frameworks:** Many newer AI applications are predominantly built with native code, indicating a trend away from cross-platform frameworks.
- **Misleading download statistics:** The video debunks the idea that increased npm downloads for React Native necessarily reflect increased adoption.

The creator advises viewers to critically evaluate claims about mobile app frameworks and to prioritize what companies _do_ rather than what they _say_.
